# Инструкции для работы с репозиторием

- Сервис: NestJS / TypeScript, PostgreSQL, RabbitMQ. Контракт и допущения — README.md и DECISIONS.md.
- Работать в отдельной ветке. Не коммитить .env, секреты, node_modules, dist и данные контейнеров.
- Сначала читать затрагиваемый код и тесты. Сохранять чужие изменения.
- Идемпотентность по betId, необратимый rollback и атомарность записи ставки/счёта — обязательные инварианты.
- Суммы считать через decimal.js и PostgreSQL NUMERIC; не переводить денежные расчёты в JavaScript Number.
- RabbitMQ ACK допустим только после COMMIT. Невалидные и конфликтующие события должны попадать в DLQ.
- Изменения схемы оформлять новой SQL-миграцией; не менять уже применённые миграции.
- Минимальная проверка: npm run check и npm test. Для БД/очереди/контракта также npm run test:integration на изолированных тестовых ресурсах.
- Не запускать разрушающие проверки против чужой или рабочей БД. Интеграционные тесты используют отдельную схему PostgreSQL и уникальный префикс очередей.
- Документировать изменения поведения и существенные допущения. Не выдавать локальные проверки за CI или публикацию.
- Публикация репозитория, merge и deploy требуют разрешения в текущей задаче.

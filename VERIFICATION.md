# Проверки реализации

Дата: 6 ноября 2026 года. Проверки выполнил Codex локально; это не отчёт GitHub Actions.

| Проверка | Результат |
| --- | --- |
| `npm run check` | TypeScript: успешно |
| `npm test` | 32/32 модульных теста |
| `npm run test:integration` | 19/19 интеграционных тестов, реальные PostgreSQL и RabbitMQ |
| Docker build, установка `npm ci` внутри образа | Успешно |
| Запуск Compose и `/health` | Все три сервиса healthy |
| `docker compose run --rm producer demo` | Брокер подтвердил 8 событий; результат лидерборда соответствует README |
| Повтор демо после пересоздания контейнера приложения | Очки сохранились, повторного начисления нет |
| `npm audit` | 0 известных уязвимостей по ответу реестра на момент проверки |

Проверены точность до 16 дробных знаков, валидация дат/сумм/настроек,
конкурентные дубли и начисления разных ставок одному игроку, отмены до/после расчёта,
гонки расчёта с отменой, конфликт владельца/расчёта, фиксация и удаление курса,
топ-100 и позиция 105, HTTP 400, некорректный JSON и конфликты в DLQ,
ограниченные повторы с задержкой, исчерпание повторов и отсутствие маршрута публикации.

Отдельно проверены фактическое закрытие AMQP-канала с восстановлением consumer
и искусственная ошибка после завершённого COMMIT с повторной обработкой без двойного начисления.
Это моделирование ошибки после коммита, а не аварийное завершение процесса ОС.

Ограниченное ревью кода охватило транзакции, очки, лидерборд и восстановление AMQP.
Найденные ошибки проверки нулевого курса и восстановления закрытого канала исправлены.
Тестовые схемы и очереди создавались с уникальными именами и удалялись после тестов.

Не выполнялись нагрузочный тест, аварийное завершение ОС-процесса, проверка отказа
кластера RabbitMQ или полный аудит безопасности. Локальный RabbitMQ состоит из одного узла.
Workflow CI добавлен, но удалённый CI не запускался. Публикация репозитория и production deploy
не выполнялись. Демонстрационные контейнеры после проверки остановлены; локальные тома сохранены.
